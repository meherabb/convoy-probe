# Registration record

Every confirmatory test of the paper had its sample rule, estimator and verdict rule fixed in code
before the data it applies to were generated or, for H14, computed. The files in this folder are the records the notebook
wrote (`results/v6.6/manifest/`, byte-identical; `tests/test_registered.py` checks this); the
constants they fix are `PREREG` and the design dictionaries of notebook cell 0.4, mirrored in
`src/convoy/registered.py`.

| File | Written | What it fixes |
|---|---|---|
| `idea_lock.json` | before any model was run (v5) | the question, the propositions, assumptions A1–A3, and the locked predictions P1–P4 with their verdict rules; A1 is tested by the knockout |
| `amendment_v6.json` | after the v5 results (P1 had failed), before any E5 image existed | H5–H8 (ground-contact ablation E5); H9 (driving) and H10 (attention masks), both later withdrawn from the confirmatory set |
| `amendment_v6_1.json` | before the real-image composites existed | H11a–b (E5-REAL); H10 withdrawn; H9 moved to exploratory because its sample rule was replaced after the registered rule had left too few vehicles |
| `amendment_v6_2.json` – `amendment_v6_4.json` | before the data of each analysis | exploratory analyses only (masks by support, contact in traffic, the convoy case, Argoverse 2, the synthesis across testbeds); no registered verdict depends on them |
| `amendment_v6_5.json` | before the baseline-sweep and dose-response renders existed | H12 (baseline sweep, registered for DUSt3R and MASt3R) and H13 (15 cm wall); the twin test with labelled correspondences is exploratory |
| `amendment_v6_6.json` | before any optical flow or road plane of Argoverse 2 was computed | H14 (twin test with flow); registered on images and labels that had been used before, but on quantities that had not been computed |
| `decisions.json` | throughout | 64 implementation decisions, corrections and deviations (D1–D64) and two errata of the idea lock (E1, E2), each with its reason |

## Verdict rules

* **P1** (models inherit the degeneracy): SUPPORTED if `β_s ∈ [0.8, 1.2]` with its 95% interval inside
  `[0.5, 1.5]`; FALSIFIED if the interval lies outside `[0.5, 1.5]` or `R² < 0.5`; PARTIAL otherwise.
* **P2** (masks miss parallel movers): recall(perpendicular) − recall(parallel), matched on |s| and object
  area, at 5% static false positives; SUPPORTED if at least 0.3 with an interval above zero.
* **P3a/b, P4**: as stated in `idea_lock.json` (Spearman > 0.5; class contrast; `β_s ∈ [0.8, 1.2]` on straight paths).
* **A1** (correspondence-based depth): HOLDS if deleting the mover from the second view lowers `β_s`
  (interval of the drop above zero).
* **H5–H14**: SUPPORTED if the 95% cluster-bootstrap interval of the contrast lies above zero,
  CONTRADICTED if it lies below zero, NOT SUPPORTED otherwise; NOT TESTABLE below the minimum sample
  (8 movers in 5 base scenes for H12–H13; 20 vehicles in 10 tracks for H14).

All intervals are 95% percentile intervals of a cluster bootstrap with 10,000 resamples (cluster:
scene, image pair or vehicle track). Holm-adjusted bootstrap p-values across the six models are
reported alongside (`results/v6.6/results/prediction_summary.csv`). Implementations:
`convoy.stats.verdict_p1`, `verdict_p2`, `verdict_positive`.
